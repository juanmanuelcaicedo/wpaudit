# Política de seguridad

Si encuentras una vulnerabilidad en wpaudit, repórtala de forma privada con
[GitHub Security Advisories](https://github.com/juanmanuelcaicedo/wpaudit/security/advisories/new).
No abras un issue público.

**No publiques informes reales.** Los archivos que genera wpaudit describen debilidades,
usuarios y versiones de un sitio. Si necesitas compartir un caso, elimina primero esos datos.
